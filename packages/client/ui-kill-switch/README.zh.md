# @deepseek-ai/dsh-client-ui-kill-switch

[English](README.md) | 中文

Web 客户端插件，贡献 `kill-switch` 命令：一个经确认的动作，向实时列表中的每一个会话扇出 `session.cancel`，中断所有正在运行的回合。唯一的 popup 选项携带共享外壳的风险确认（`SelectOption.confirmation`），必须先勾选确认步骤才会执行；确认按钮标注实时会话数量，结果统计（"已向 N/M 个会话发送停止指令"）经发起会话的输入框通知通道回报。设计上尽力而为：某一个会话忙碌或拒绝不会中断其余的扇出。

排队中的消息会保留——取消语义归运行时所有（宿主达到取消静默后，待处理工作按 FIFO 恢复）。

## 范围

当前覆盖：所有列出会话正在运行的智能体回合（含由运行时路由的子代理中断）。浏览器尚不可达、因此延期到相应线面出现之后：任务终止（`ctx.jobs` 在宿主侧）、终端清理（无客户端面）、已加载模型卸载（`ctx.models` 在 E4 之前没有服务提供者）——随这些缝隙落地，本命令将长出对应的分支。

## 组装

```yaml
- id: ui-kill-switch
  name: '@deepseek-ai/dsh-client-ui-kill-switch'
```

## Model Experience

自身无：取消只改变调度；排队消息仍会运行，任何内容都不被删除或编辑。

#### KV Cache 影响

无；本插件从不组装或发送提供商请求。被中断的回合只是停止生成——部分输出语义由提供者负责。

## 已知限制与延期工作

- **任务/终端/模型未覆盖**——这些今天还没有浏览器可达的缝；见范围一节。
- **统计仅限通知**——结果只渲染在发起会话上，与其他仅客户端命令结果的呈现方式一致。
