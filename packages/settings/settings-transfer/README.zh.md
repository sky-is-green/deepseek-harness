# @deepseek-ai/dsh-settings-transfer

[English](README.md) | 中文

面向工作室迁移的导出/导入包：所有已注册设置命名空间的用户层（含模型档案）与本地创作预设，打包为一个带版本号的 JSON 文件。导入主机会在持久化之前通过自身注册的所有者重新校验全部内容。

## 契约

- **导入绝不发明所有者。** 包中的命名空间段落只有在本机已注册时才会生效；其余一律跳过并说明原因，因为没有模式所有者的段落无法校验。
- **生效段落先通过其所有者模式。** 本机所有者拒绝的取值会令写入失败；不会留下部分生效的状态。
- **预设导入不越过创作信任边界。** ID 必须是合法的预设目录名，文件只按字节复制进用户可写根目录，已存在的同名预设默认跳过，除非显式传入 `overwritePresets`。系统预设永远不可触及。
- **导出只携带用户覆盖层。** 组合 `base` 层与模式默认值属于各部署自身的配置；导出它们会把本机的组合强加到其他主机上。
- 包格式带版本号；`readBundle` 会拒绝本构建无法理解的版本，而不是猜测。

## 模型体验

### 模型看到什么

本身看不到任何东西。导入的设置只会通过读取相应命名空间的功能影响模型（例如加载时应用的按模型档案），并受其既有的校验与预算约束。

### Token 影响

自身没有影响。导入的 `systemPrompt` 类字段只在消费功能应用它时才计入 token。

### KV 缓存影响

导入档案中的 `contextLength` 若在加载时被应用，会按档案接缝的文档决定服务端窗口大小。

## 已知限制与延后工作

- **仅支持组合文件预设。** 包内预设携带其 `agent.cordis.yml`；预设目录中的其他附属文件暂未捕获。
- **尚无选择性导入。** 包按整个命名空间生效；字段级挑选等待需要它的消费方出现。
