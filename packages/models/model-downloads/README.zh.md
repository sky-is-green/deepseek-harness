# @deepseek-ai/dsh-model-downloads

[English](README.md) | 中文

`ctx.models` 背后的分程下载引擎：`resolveRemoteFile` 以 HEAD 探测兼容 Hugging Face 的 hub（跟随重定向，捕获大小与 LFS 风格 sha256 etag），`fetchToFile` 把文件流式写入 `.part` 暂存、支持 Range 续传、校验完整性后原子改名就位。本包不理解模型目录或事件——那些归 provider 所有。

## 约定

- **暂存与落位**：字节写入 `<destinationPath>.part`；最终文件只在校验通过后经原子改名出现。目标目录必须已存在；已存在的最终文件会被覆盖。
- **续传**：暂存存在时以单条 `Range: bytes=<size>-` 请求继续（暂存前缀同样参与哈希）。服务器改答 `200` 触发一次干净重启；`416` 在尺寸与摘要都吻合时就位「已完成但未改名」的暂存文件，尺寸不符则响亮拒绝。
- **完整性**：hub 公告的 sha256（或显式 `expectedSha256`）在流式结束后校验；不符即删除已落位文件——已知错误的字节绝不留给下次续传。
- **取消返回、失败抛出**：任何阶段的中止都以 `{ result: 'cancelled' }` 结算并保留暂存；HTTP、文件系统与完整性失败则以具体状态码或摘要拒绝。
- **进度节奏属于调用方**：引擎逐 chunk 发样本外加一次收尾样本；节流由消费者实现。

## 模型体验

### 下载面

#### 模型看到什么

什么都不直接看到：本包只搬运权重文件。一切模型可见的内容都始于已完成文件被服务器加载之后。

#### Token 影响

无直接影响；下载仅搬运权重文件，模型加载后才可见。

#### KV Cache 影响

此层无；权重搬运先于任何 KV 缓存。

## 已知限制与暂缓事项

- **单 hub、匿名**——请求只寻址调用方提供的基础 URL，没有凭据或镜像回退策略；鉴权属于尚无消费者行使的 seam。
- **单流传送**——高延迟链路上的超大文件没有并行分块扇出。
- **无代理／TLS 定制**——传输沿用 Node fetch 的环境默认。
